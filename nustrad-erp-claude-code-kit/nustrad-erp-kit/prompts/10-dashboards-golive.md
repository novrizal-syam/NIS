# 10 · Dashboards, integrations, hardening, go-live
1. Live process map (swimlane: Revenue/cash in, Spend/cash out, People, Finance × 6 phases) with clickable live counts; role dashboards (Director, Sales, Operation, Finance, HC); OKR 2026 (revenue vs RJPP Rp 25 M, new contracts ≥ Rp 80 M, win rate ≥ 45%, invoice-to-cash < 30 days, cost overrun −15%, utilisation ≥ 85%, downtime < 3%, net margin, cash ≥ 6× monthly opex, zero tax penalty, zero accident) with yearly targets in settings; monthly management pack PDF in the Nustrad report style.
2. Integration adapters with "manual/file" mode until credentials exist: Coretax via PJAP, bank files and host-to-host, PSrE, e-Meterai, SMTP, WhatsApp Business API; documented REST API (OpenAPI).
3. Client portal (tickets, invoices, packs) and vendor portal (RFQ, invoice upload, payment status).
4. Security review of every endpoint (RBAC, SoD, sensitive fields), encryption of sensitive columns, PDP consent and breach log, daily backups with tested restore, separate dev/staging/prod.
5. Performance: indexes, pagination, main pages < 2 s with 50,000 transactions; Playwright end-to-end for the whole scenario (lead → contract → lock → MR/PR → blocked → BCR → RFQ → PO → GR → vendor invoice → DOR → ticket with dispute → invoice → receipt → payroll → payment run → tax → close; plus CAPEX and SOP → training).
6. Go-live: remove demo data, opening balance wizard, admin README and role user guides in Bahasa Indonesia, production deployment guide (Docker on a Jakarta-region VM or managed Postgres, HTTPS, backups, monitoring).
