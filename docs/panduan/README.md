# Panduan pengguna per peran

Nustrad ERP untuk PT Global Energi KITA. Pilih panduan sesuai peran Anda; satu orang boleh
memegang beberapa peran (ganti peran aktif di menu pengguna kanan atas).

| Panduan | Untuk peran |
| --- | --- |
| [Mulai di sini](mulai.md) | semua pengguna |
| [Direktur](direktur.md) | Direktur, Pemegang Saham (RUPS) |
| [Penjualan](penjualan.md) | Account Executive, Head of Sales |
| [Operasi dan lapangan](operasi.md) | Lead Engineer (planner), Engineer, Field Engineer, OFS Superintendent, Head of Operation |
| [Pengadaan dan gudang](pengadaan-gudang.md) | Procurement Officer, Warehouse Head, Asset & Inventory Coordinator |
| [Keuangan](keuangan.md) | Billing Admin, AP Accountant, Kasir, Tax Specialist, Lead Controller, Head of Finance |
| [SDM dan penggajian](sdm.md) | HCBP Officer |
| [QHSE, dokumen dan pelatihan](qhse-dokumen.md) | QHSE Coordinator, pemilik dokumen, semua karyawan |
| [Portal klien dan vendor](portal.md) | Client Representative, Vendor |

Admin dan Super Admin: lihat `docs/admin/README.md`.
