# Panduan SDM dan Penggajian (HCBP)

## Data karyawan
- Data Master → Karyawan: gaji pokok, tunjangan tetap, status PTKP, NPWP, NIK, rekening.
  NIK, NPWP dan rekening disimpan terenkripsi dan hanya tampil bagi yang berizin.
- Sertifikat kru (H2S, BOSIET, dll.) dengan tanggal habis; kru tanpa sertifikat wajib tidak
  bisa dipilih di DOR. Perpanjangan diunggah di Pelatihan.

## Penggajian bulanan (cut-off tanggal 25)
1. **Penggajian** → *Hitung penggajian* untuk periode: hari lapangan dan lembur diambil dari DOR yang
   disetujui; BPJS dengan batas upah, PPh 21 TER (Desember: rekonsiliasi tahunan).
2. Koreksi hari kerja hanya dengan alasan (tercatat sebagai manual).
3. *Ajukan*; penghitung tidak boleh menyetujui. Head of Finance menyetujui → jurnal biaya per
   proyek (5100) dan kantor (6100).
4. Dibayar lewat payment run (AP menyiapkan, HoF menyetujui, Kasir merilis).
5. Karyawan melihat slipnya di **Slip gaji saya**.

## Pelatihan
- Pelatihan (LMS): matriks kompetensi per jabatan, jadwal kelas, kuis, kehadiran, anggaran
  dan paket bukti (Excel) untuk audit.
